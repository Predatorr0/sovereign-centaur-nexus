1.2 Oracle and Brain Layers

The most critical architectural decision, approved by Lexzyy, is the separation of the system into C++ Oracle and Python Brain layers.

C++ Oracle: Direct access to the game's physics engine (`CCharacterCore`). Handles A* pathfinding and Risk-Jacobian sonar diagnostics.

Python Brain: Operates the LPSD (Latent Phase-Space Diffusion) model. Processes the 11-dimensional state manifold received via Shared Memory.

1.3 Nekomata // Why Shared Memory?

Shared memory remains in user space, eliminating kernel context switches and reducing latency to nanoseconds. This provides a vital "wait-free" guarantee within the 20ms physics tick.
