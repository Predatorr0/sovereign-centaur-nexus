§02 Bölüm 1: Projenin Temelleri

1.1 Proje Nedir ve Ne Hedefliyoruz?

Sovereign Centaur, DDraceNetwork (DDNet) adlı platform oyunu için geliştirilmekte olan, insan üstü performansa sahip otonom bir navigasyon botudur. DDNet, 50Hz tick-rate ile çalışan hassas bir oyundur. Oyunun temel mekaniği hook (kanca) sistemi etrafında şekillenir. AiP-Gores gibi ileri seviye haritalarda bu mekaniğin milisaniye hassasiyetiyle kullanılması gerekmektedir.

Tier 1: Map Completion

Haritayı freeze ve death tile'lara girmeden bitirme kabiliyeti.

Tier 2: TAS-Quality

Minimum sürede, kusursuz hook swing mekanikleriyle rekor denemeleri.

1.2 Oracle ve Brain Katmanları

Mimarinin en kritik kararı, sistemin C++ Oracle ve Python Brain adlı iki bağımsız katmana ayrılmasıdır. Lexzyy tarafından onaylanan bu ayrım, performans zorunluluğundan doğmuştur.

C++ Oracle: Oyunun fizik motoruna (`CCharacterCore`) doğrudan erişir. A* algoritmasıyla yol planlaması yapar. Risk-Jacobian Sonar ile tehlikeleri tespit eder.

Python Brain: LPSD (Latent Phase-Space Diffusion) modelini çalıştırır. Shared Memory'den gelen 11 boyutlu state vektörünü işler. Trajektör öngörüsü üretir.

1.3 Nekomata // Shared Memory Neden Seçildi?

Shared memory user space'te kalır, kernel geçişi yoktur ve gecikme nanosaniye mertebesindedir. Bu bütçeli 20ms'lik döngüde hayati önem taşıyan bir "wait-free" garantisi sağlar.

// C++ struct DiffusionBrain (v0x7500B1)
struct DiffusionBrain {
    std::atomic<uint64_t> sequence_counter; // Seqlock
    int predicted_actions[100];
    float predicted_target_x[100];
    float predicted_target_y[100];
    float waypoint_x[100]; // Phase 72
    float waypoint_y[100];
};
